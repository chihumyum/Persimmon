# Support

For usage help, supported book formats, privacy information, and contact
details, visit [persimmon.cc/support](https://persimmon.cc/support).

Use GitHub Issues for reproducible bugs and focused feature proposals. Before
filing a bug, check that the book is DRM-free and reflowable EPUB 2 or EPUB 3,
then include the platform, Persimmon version, expected behavior, and actual
behavior. Do not upload copyrighted books or private reading data.

Security vulnerabilities must be reported through [SECURITY.md](SECURITY.md),
not through public Issues. Support is provided on a best-effort basis without a
response-time commitment.
